## Project Structure

This repository includes the following folders for reference:

- **isaaclab**: Local copy of the IsaacLab source code used for development and execution.
- **isaaclab_assets**: Fork/copy of IsaacLab assets for easy reading and reference.
- **isaaclab_tasks**: Fork/copy of IsaacLab tasks for easy reading and reference.

> **Note:** The `isaaclab` folder contains the actual, active source code used in development and execution.
